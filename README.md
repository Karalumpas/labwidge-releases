# IpTrayWidget – udgivelser

Her ligger installationsprogrammet til IpTrayWidget: elpris, system og netværk ved uret i Windows.

**Installér:** hent `IpTrayWidget-Setup.exe` under [Releases](https://github.com/Karalumpas/ipwidget-releases/releases/latest) og kør den.
SmartScreen kan vise "Windows beskyttede din pc" – vælg "Flere oplysninger" → "Kør alligevel".

**Opdatering:** appen tjekker selv dette repo ved opstart og én gang i døgnet og spørger, før en ny version installeres.
Du kan også vælge "Søg efter opdateringer…" i menuen ved uret.

Kildekoden ligger i et privat repo; dette repo indeholder kun de færdige installationsfiler.
